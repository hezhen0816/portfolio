上課紀錄工具

上課錄音自動轉成逐字稿，再對照當週 Moodle 講義整理成上課紀錄。轉寫在自己的 GPU 主機上跑，錄音不上傳第三方；逐字稿和講義文字會送 Claude API 整理。

  • Swift／SwiftUI
  • Python
  • Qwen3-ASR
  • Claude API
  • Moodle 爬取

GitHub 原始碼 ↗

以 Claude Code、Codex 等 AI 代理協作開發：需求、架構與技術選擇、實驗設計與結果判讀由本人與 AI 討論後決定，程式碼主要由 AI 撰寫。

架構

  1. 錄音Mac 選單列 App
  2. 產生專有名詞提示詞依當週講義
  3. 轉寫家用 GPU 主機跑 Qwen3-ASR 1.7B
  4. 整理上課紀錄與重要事項Claude 對照講義
  5. 通知

失敗時進補送佇列，每 30 分鐘重試。iOS 版經 HTTPS 上傳到同一台伺服器，可以續傳，並用 SHA-256 去除重複。

轉寫模型比較

取 4 段各 3 分鐘的錄音，數 45 個關鍵詞中了幾個。

代理指標

沒有人工逐字稿，所以這不是字錯率，只能看關鍵詞有沒有被聽對。

  • Gemini（雲端）44/45
  • Qwen3-ASR 1.7B39/45
  • Qwen3-ASR 0.6B37/45
  • FireRedASR232/45
  • Breeze31/45
  • Fun-ASR-Nano27/45

雲端的 Gemini 命中最多，但我不想把上課錄音上傳到第三方，所以留用本機模型裡最好的 Qwen3-ASR 1.7B（藍色）。

目前的限制

  • 沒有人工逐字稿，比較只能用關鍵詞命中當代理指標。
  • 數字與專有名詞偶爾會轉錯。
  • iOS 版有部分實機項目還沒確認。
