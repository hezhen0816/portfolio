兼職・2026.07 – 2026.09

大金防火科技 內部系統

把報價、寄信、圖說、詢價、工務、會計等原本靠人工與 Excel 的作業，做成公司內部的網頁系統，給同事與工務主任使用。

  • Python
  • FastAPI
  • React／TypeScript
  • ezdxf
  • openpyxl
  • PWA
  • NSSM

架構

七個獨立專案，在公司的 Windows 主機上以服務常駐。資料每晚加密備份到 NAS。

圖中的長條是各子專案的 commit 數，幾乎都是我提交的。

圖說自動化

輸入報價單與建築圖，輸出防火門的樓層明細表與標註平面圖。

34 樘

在公司主機以實案完整試跑，明細表與標註圖和既有人工成品相符

  1. 讀入報價單 xlsx 與建築圖 DWG
  2. 解析標號與樓層
  3. 人工複核程式解析完，由人確認後才產出
  4. 產出樓層明細表
  5. 產出規格表拉線標註的平面圖

工務管控

把原本的 Excel 管控表改成系統，現場用手機網頁操作。

  • 拍照丈量回報，可在照片上標註，照片自動歸檔。
  • 收訊不好時照片先存在手機，恢復連線後自動補傳。
  • 選手機網頁而不做 App 的原因：免費開發者簽章每 7 天就失效。

詢價系統

「規則建議」這一步是用事先寫好的規則比對出來的，不呼叫 AI 模型，所以沒有 API 費用。

另外，寄信系統管理推廣信與退訂名單。

  1. 上傳
  2. 解析成初稿
  3. 表格編輯
  4. 規則建議
  5. 產出詢價單

目前的限制

  • 圖說的複核步驟還沒有經過同事實際使用驗證。
  • 工務的手機網頁還待工務主任實機驗證。
  • 展開自動化沒有經過實際折床校正。
